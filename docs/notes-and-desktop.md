# 笔记、桌面助手与界面偏好

## 笔记库、关联与冲突保护

- 论文库下方新增「笔记库」。每个研究空间独立保存 Markdown 笔记；一篇笔记可关联多篇论文与多个技术节点，同一对象也可关联多篇笔记。详情页通过「笔记标题 →」跳转。删除节点/论文只移除关联，不删除笔记；论文去重会迁移笔记关联。
- 笔记支持标题/正文搜索、Markdown 工具栏、分栏/编辑/预览、公式和表格、撤销/重做、Ctrl+S 保存、自动保存及 `.md` 导出。草稿保存在当前浏览器本机，失败时可恢复；多窗口版本冲突会阻止覆盖并保留草稿，先导出或复制后可重新载入最新版本。笔记正文上限 500,000 字符，包含在研究空间 JSON 导出中，不包含在个人配置文件中。

- 技术详情始终显示「关联笔记」和「新增笔记 →」；点击直接创建以当前显示的技术名称命名的笔记，关联该节点并打开笔记编辑页，已有笔记链接仍保留。

关联笔记入口位于技术「重要性判断」下方及论文「阅读导览」下方。从阅读器打开的笔记复用同一份数据与编辑器。见[阅读侧栏](reader-and-translation.md#阅读侧栏)。

## 编辑界面、沉浸模式与文本光标

- 笔记编辑框与文本输入使用本地深色、白色描边的 I 形鼠标指针，替代系统默认的反色/浅色文本指针；插入光标也明确使用深色。普通和沉浸编辑共用此规则。

- 快速笔记的「置顶」按钮用深色表示开启、浅色表示关闭。笔记工具栏右侧提供「沉浸编辑」：只保留工具栏、编辑/预览和保存状态，铺满当前页面但不改变系统窗口大小；再次点击或按 Esc 返回，保留内容与撤销历史。

## Windows 桌面快捷助手

- Windows 使用 `npm start` 时自动启动后台笔记助手，默认系统全局快捷键 **Alt+I**；无需浏览器处于焦点，应用服务必须保持运行。快捷键可在齿轮配置修改，点击「保存偏好选项」生效；占用冲突不会解除旧组合。快速窗口可切换研究空间、打开或创建任一笔记、编辑和关联对象；「置顶」使用系统窗口置顶并保存偏好。关闭窗口隐藏到后台，托盘菜单可重新打开或退出助手；退出应用服务会释放快捷键。开发模式不自动注册，`DISABLE_DESKTOP=1` 可关闭桌面助手。网页快捷页为 `/?quick-notes=1`，普通浏览器不具备系统置顶能力。

- 桌面助手使用 Electron 的 [globalShortcut](https://www.electronjs.org/docs/latest/api/global-shortcut) 和 [BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window)。Electron 二进制首次安装需要下载；GitHub 不可达时，可按[官方安装说明](https://www.electronjs.org/docs/latest/tutorial/installation)设置当前终端 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后运行 `node node_modules/electron/install.js`，仍使用包内官方校验值。

## 本地字体与中文排版

- 界面随应用打包 Noto Sans SC 的 400/700 静态字重（500 使用 400，600 使用 700），按字符范围加载本地字体分片，不依赖在线字体服务或系统中同名字体。图谱图标使用 SVG，避免字符符号被字体替换。字体来源为固定版本 `@fontsource/noto-sans-sc@5.3.0`，SIL OFL 许可证随应用发布于 `public/licenses/Noto-Sans-SC-OFL.txt`。
- 中文排版测试检查字体实际加载、中文字宽、桌面/窄屏及缩放。Chrome 还检查标题实际使用的字体来源；`npm run test:firefox` 在构建后使用本机 Firefox 独立配置与数据库，生成 `test-results/firefox-fonts/` 截图，不修改用户的浏览器配置。可通过 `FIREFOX_PATH` 指定 Firefox 路径；90% 场景为页面 CSS 缩放。

## 个人配置与导航

| 愿景能力       | 当前实现                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 界面           | 中文界面、可折叠左右栏、可调聊天宽度、窄屏布局、加载与错误反馈                                  |

- 配置底部「保存偏好选项」统一保存上方待提交的节点直径、主题、动效、语言与模型/学习偏好；未配置 AI 也可保存外观。上方「保存外观配置」仍可单独使用。重新打开窗口、刷新及导出使用的是已持久化的设置。
- 头像旁齿轮打开「自定义配置」，原侧栏设置入口同样可用。可修改 AI 接口、模型与密钥，选择中英文标题，独立设置四级技术节点直径（8–128px，默认 78/62/52/14px），选择松林绿/海洋蓝/鸢尾紫/暖砂金主题，减少界面动效或恢复默认外观。配置保存在本机 SQLite，所有研究空间共享；节点大小会同步到全部技术布局，文字避让随尺寸调整。
- 顶部导航显示「AnIStudy → 当前研究空间 → 当前页面」，研究空间和页面名称均为可点击的下拉框，支持键盘操作；与侧栏同步更新，折叠侧栏后也可切换。切换空间保留当前页面类型，关闭旧节点详情并加载该空间资料，最后选择的空间在刷新后恢复。窄屏将导航与右侧操作分为两行，长空间名截断显示，可通过悬停或下拉查看完整名称。
- 配置支持 JSON 导出和导入，包含已保存的模型地址、模型名称、语言、学习/思考偏好和外观；不包含 API Key、论文或空间数据。导入会验证版本和字段，失败不改动原配置；接口地址发生变化时清除旧密钥，防止把它带到不同服务商。

年份换列、节点显示及布局参数见[图谱视图与交互](graph-and-data.md#图谱视图与交互)。独立模型设置见[任务模型参数与执行进度](chat-and-models.md#任务模型参数与执行进度)。
