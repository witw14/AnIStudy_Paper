# 论文入库、图谱与路线规则

## 功能范围

| 愿景能力       | 当前实现                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 论文库         | PDF 保存/提取/阅读，arXiv 核验导入，搜索与状态筛选，删除与引用清理                              |
| 技术图谱       | 年份时间轴、8 类颜色、4 档重要程度、资料实线/缺失虚线、方向筛选、搜索、缩放、节点详情           |
| 论文图谱       | 独立的论文关系图，与技术节点双向跳转                                                            |
| 图谱维护       | AI 按必要性筛选后自动入图，重复整理合并已有节点；明确关系类型，区分 Uses 与 Introduced by       |
| 学习路线       | 目标→阶段→能力→论文，必要旁支、验证后的推荐、选择计划、技术完成进度                             |

## 论文导入、身份核验与去重

- 导入 arXiv 链接/ID，或者上传 PDF（最大 30 MB）。arXiv 导入会核验标题、作者、年份与编号，只获取摘要，不自动下载全文。

- PDF 导入会读取文档元信息和 arXiv 编号，并按编号、规范化标题、文件内容自动去重；同一篇论文的本地 PDF 和网络元信息合并保留。也可手动附加到已有论文。

- 论文年份采用最初公开/预印本年份；arXiv 修订年和会议年可能不同。无法识别的年份显示「年份待识别」，不再使用上传年份代替。

- AI 历史归因与推荐相关性仍需人工核对。arXiv 核验保证编号、标题与元信息匹配，不能代替论文内容审查。核验网络失败时可重试，不会把失败项标记为 Verified。

- 论文库提供上传时间新→旧、旧→新，以及论文年份新→旧→未识别、未识别→旧→新四种排序。默认按上传时间新→旧，选择保存在当前浏览器；上传时间使用首次加入记录的时间，与发表年份及整理时间分开，搜索和状态筛选继续生效。

## AI 整理、原文定位与分类

- 打开论文，点击「整理论文 · 提取技术」。AI 筛选核心技术与必要前置，自动加入技术节点、技术关系及论文关系，同名或同义别名合并，不再要求逐项确认。被判定为无关细节的节点不入图，动态保留筛选结果。

- 设置中的「保留英文专有名词」默认开启，技术标题使用英文，讲解保留中文。开关可独立保存，不要求先配置模型。旧资料可点击「修复已有资料」补齐元信息、英文别名和研究方向。

- 技术首创年份也允许未知，综述年份不能替代技术年份；重新整理不会用未知年份覆盖已有年份。整理结果逐项校验保留，完整 JSON 字段可从截断输出中恢复；无有效摘要或节点时最多简化重试一次。模型不可用时保留旧摘要或标明来源的原文摘录，动态展示降级原因，不编造技术或关系。

- 后续整理论文为每项关联技术生成本文专属的两句话概括，第一句说明作用，第二句说明实现/使用方式，放在论文详情「关键技术」卡片中。复用已有技术也生成当前论文的概括，按论文与技术的关联保存，不覆盖其他论文的解释。原资料未交代实现时明确说明；输出缺失或不完整时保留已有有效句子、显示待补充说明并报告整理局限，不因此丢弃技术。旧论文可通过重新整理生成概括。

- 研究方向与技术类型由 AI 根据当前空间和论文主动发现，不预设计算机视觉类别。模型获得当前空间已有分类、别名和节点，优先复用相同概念，按需创建新类别；服务器按名称与别名归一并随空间保存，只展示实际有节点的分类，空空间没有分类预设。旧分类可通过重新整理论文或「修复已有资料」更新，已有节点和学习进度保留。历史英文 ID 的中文映射仅用于显示旧数据。

整理提交的原文最多 85,000 字符，超出范围必须注明局限。技术证据使用有效的 `sourceParagraphIds`，由服务端校验论文和段落归属。见[段落定位、检索与证据](reader-and-translation.md#段落定位检索与证据)。

## 技术信息、手动修改与重要性校准

- 论文/技术详情的标题与正文右上角新增小铅笔，支持手动修改和取消；技术标题可分别修改中英文版本，正文支持 Markdown。用户修改记录会在 AI 重新整理和资料修复后保留，原始 PDF 文件不变。

- 技术详情的「更改信息」可手动填写年份（留空表示待识别）并选择四档级别，立即保存并调整图谱大小。手动级别优先于 AI，重新整理论文与批量评估均保留；选择「允许 AI 重新定级」后，下次整理或评估可更新。AI 整理始终要求每个知识点的英文与中文标题，语言开关只改变显示；缺少一种标题时尝试补全，模型失败则保留已有信息并提示。
- 重要性与入图必要性分开判断：里程碑需要领域范式或基础突破依据，重要需要分支级关键贡献，普通用于常规/局部方法或影响证据有限的技术，次要用于实现细节及被替代的局部辅助机制。模型返回贡献角色、影响范围、后续影响和中文定级理由；服务端校准与这些依据矛盾的高等级，不按名称硬编码，不强制等级配额。历史里程碑不会仅因被新技术替代而降级。节点详情可查看理由。
- 次要技术使用直径 14px 的空心小圆，保留 44px 隐形点击区域和完整文字标签，其他等级保持原大小；全部布局共用此规则。已学状态使用小绿点，避免遮住小圆。
- 旧节点可在「模型设置」点击「重新评估技术重要性」；按当前空间逐批评估，完整返回后自动应用，无需逐项确认。保存前备份到 `data/backups/`；模型失败或结果不完整时保留原等级，评估期间发生内容/等级修改的节点跳过，保留最新学习状态及其他记录。

- 关联笔记入口位于技术「重要性判断」下方及论文「阅读导览」下方。「相连的技术」右侧铅笔可编辑关系，区分当前相连/未相连技术；后者支持中英文搜索、每页最多 20 个。下拉关系以当前技术为主语，支持使用/被使用、扩展/被扩展等所有现有关系及「无关系」，修改同一条图谱边同步更新双方详情。手动年份和关系（包括移除关系）不会被后续 AI 整理覆盖；从相连技术跳转会重置详情滚动到顶部。

## 图谱视图与交互

- 技术图谱默认使用关系聚类，也可切回时间轴。聚类根据直接关系、共同论文及选中学习路线分组，技术群可点击标题重命名；新增节点尽量保留已有位置，需按更新后的关系重新分组时可点击「重新聚类」。分组、群名和总览视图保存在当前浏览器，按研究空间隔离。启发/推广连线默认隐藏，悬停关联节点时显示，也可手动全量开启；共现只用于布局，不会伪造新的技术关系。
- 节点详情点击「以此技术为中心」进入局部视图：左侧仅放入 Requires 必要前置，中间是当前技术及 Uses 核心组成，右侧是后续使用/扩展/改进，下方是相关、来源与替代技术。只展示目标的直接关联，点击另一个节点详情可更换中心；所有布局共用节点、关系与学习状态。
- 图谱下方的全部技术条目默认折叠。展开后可按节点资料类型、技术种类、研究方向、重要程度和学习状态复选筛选；组内取并集，组间取交集，不勾选时显示该组全部。滚轮在图谱内滚动至边界后不会传递到外层页面，Shift+滚轮可横向滚动。
- 图谱工具栏提供横向和纵向间距滑杆，拖动实时更新；横向 160–480px，纵向 120–420px，默认 270/220px。长标签换行，纵向会为长标签保留必要空间。新增图谱高度滑杆：默认高度和上限都是浏览器完整视口高度，不扣减页面顶部区域，图谱底部可以位于当前屏幕下方；最低 360px（视口更小时以上限为准）。间距和高度按研究空间、图谱类型分别保存，支持恢复默认；缩放控制位于滑杆右侧。

- 两种图谱支持左键拖动水平和竖直视野，滚轮仍可使用；拖动超过小幅阈值时取消节点点击，普通点击与键盘操作保持可用，拖动不会滚动页面。

- 配置中的「年份浏览自动换列」默认关闭，每个年份保留一列；开启后可设定「单列最大节点数」（1–100，默认 10），同一年份超出的节点在右侧续开一列，标注列序号。技术和论文时间轴共用设置，未识别年份也遵循此上限；关系聚类和目标中心布局不受影响。支持保存偏好选项、单独保存外观及个人配置导出/导入。

- 连线不再显示关系文字，悬停或键盘聚焦也不显示标签；关系用线型区分，图例只列出当前可见关系：使用=实线，依赖=虚线，扩展=中空线，改进=中空虚线，启发=点线，提出=粗实线，推广=点划线，替代=长短划线。悬停/聚焦节点仍高亮直接关系和相邻节点。

- 技术与论文详情新增「隐藏节点」勾选框，即时反馈并自动保存，保存失败恢复原状态。它只影响图谱显示，不删除记录、关系或关联笔记；重新整理及论文去重会保留用户选择。
- 节点间距模块右侧提供「全部节点／主要节点／极简节点」切换：全部包含手动隐藏节点；主要显示所有未隐藏节点；极简只显示未隐藏的重要及里程碑技术。论文极简模式按关联技术的最高级别筛选，没有关联技术或只关联普通/次要技术的论文可在全部或主要模式查看。关系聚类、时间轴和目标中心都遵循当前模式，只显示可见节点之间的连线；显示选择按研究空间及技术/论文图谱分别保存在浏览器，默认全部节点。

各档技术节点直径的可调范围为 8–128px，默认 78/62/52/14px。设置方式见[个人配置](notes-and-desktop.md#个人配置与导航)。

## 路线生成与合并

- 输入研究目标生成路线。模型可推荐新的 arXiv 论文；系统逐篇核验编号与标题，验证失败时阻止整条路线保存。论文集合高度重叠的路线自动合并，保留不同能力目标和必要旁支。成功生成的路线由用户选择加入计划。

- 路线合并阈值：共享论文占较小路线至少 80%、占较大路线至少 65%。只共享少数前置论文的路线保持独立。
- 升级时对旧空间自动进行本地去重、年份修正、方向归类和路线合并。变更前的完整空间快照保存到 `data/backups/`，不修改或删除原始 PDF。
