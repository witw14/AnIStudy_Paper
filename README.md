# AnIStudy · Paper

基于《AI 论文与研究学习应用第一阶段产品愿景》实现的本地个人研究工作空间。

React + TypeScript 前端，Node.js + Express API，SQLite 持久化。数据和 PDF 保存在本机，默认地址为 **http://127.0.0.1:4317**。

## 启动

需要 Node.js 24 或更新版本。

```powershell
npm.cmd install
npm.cmd run dev
```

生产运行：

```powershell
npm.cmd run build
npm.cmd start
```

服务仅监听本机。可通过环境变量 `PORT` 更换端口、`DATA_DIR` 更换数据目录。首次启动默认创建明确标注的计算机视觉示例空间；设置 `SEED_DEMO=false` 可关闭示例数据。

## 使用流程

1. 创建独立研究空间，输入研究方向。
2. 导入 arXiv 链接/ID，或者上传 PDF（最大 30 MB）。arXiv 导入会核验标题、作者、年份与编号，只获取摘要，不自动下载全文。
3. PDF 导入会读取文档元信息和 arXiv 编号，并按编号、规范化标题、文件内容自动去重；同一篇论文的本地 PDF 和网络元信息合并保留。也可手动附加到已有论文。
4. 在「模型设置」配置 Chat Completions 兼容接口、模型 ID 和 API Key。接口地址应包含服务商要求的 `/v1` 等前缀，不包含 `/chat/completions`。
5. 打开论文，点击「整理论文 · 提取技术」。AI 筛选核心技术与必要前置，自动加入技术节点、技术关系及论文关系，同名或同义别名合并，不再要求逐项确认。被判定为无关细节的节点不入图，动态保留筛选结果。
6. 设置中的「保留英文专有名词」默认开启，技术标题使用英文，讲解保留中文。开关可独立保存，不要求先配置模型。旧资料可点击「修复已有资料」补齐元信息、英文别名和研究方向。
7. 输入研究目标生成路线。模型可推荐新的 arXiv 论文；系统逐篇核验编号与标题，验证失败时阻止整条路线保存。论文集合高度重叠的路线自动合并，保留不同能力目标和必要旁支。成功生成的路线由用户选择加入计划。
8. 随时切换学习状态、编辑长期记忆，在 Paper Mode 或 Research Context 中继续对话。

未配置模型时，论文管理、PDF 阅读、图谱浏览、候选确认、学习状态、记忆与日程仍可使用。不会返回模拟 AI 答案。配置后，执行 AI 操作会把相关论文内容和当前空间上下文发送至所选模型服务。

## 已实现

| 愿景能力       | 当前实现                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------- |
| Workspace 隔离 | 每个空间独立保存论文、文件引用、图谱、路线、记忆、对话、日程；服务端按空间校验所有对象          |
| 论文库         | PDF 保存/提取/阅读，arXiv 核验导入，搜索与状态筛选，删除与引用清理                              |
| 技术图谱       | 年份时间轴、8 类颜色、4 档重要程度、资料实线/缺失虚线、方向筛选、搜索、缩放、节点详情           |
| 论文图谱       | 独立的论文关系图，与技术节点双向跳转                                                            |
| 图谱维护       | AI 按必要性筛选后自动入图，重复整理合并已有节点；明确关系类型，区分 Uses 与 Introduced by       |
| 学习路线       | 目标→阶段→能力→论文，必要旁支、验证后的推荐、选择计划、技术完成进度                             |
| 学习档案       | 实时状态同步、可编辑/删除的空间记忆、最近提问                                                   |
| 双模式对话     | 默认资料优先，允许标注“无资料支撑”的知识补充；可切换严格策略，论文/空间上下文与对话历史保持隔离 |
| 首页           | 学习概览、日程与截止日期、继续阅读、知识缺口                                                    |
| 数据持久化     | SQLite WAL，PDF 独立文件，空间 JSON 导出                                                        |
| 界面           | 中文界面、可折叠左右栏、可调聊天宽度、窄屏布局、加载与错误反馈                                  |

## 当前边界

- 这是可运行的第一阶段基础版本，面向本机单用户；不包含账户、云同步、多用户权限或跨 Workspace 引用。
- 扫描件 OCR 和图像内容理解暂未实现。HTML 保留 MathML 公式、表格与图像，PDF 转换视图可能缺失这些元素。索引覆盖成功提取的正文，使用关键词、问题意图词与中英技术名称扩展检索（尚未使用向量语义模型），每次提供至多 14 个片段及 24,000 字符；检索未命中不代表全文没有相关内容。整篇概括采用章节代表片段，也不代表逐段完整阅读。整理最多提供 85,000 字符的原文，超出范围必须注明局限。
- AI 历史归因与推荐相关性仍需人工核对。arXiv 核验保证编号、标题与元信息匹配，不能代替论文内容审查。核验网络失败时可重试，不会把失败项标记为 Verified。
- AI 不会自动把用户标为「已学会」，也不会自动写入隐形长期记忆。当前长期记忆由用户显式维护。
- 不包含愿景明确暂缓的测验、评分、间隔复习、社交及复杂多 Agent 自治。
