# AnIStudy · Paper

基于《AI 论文与研究学习应用第一阶段产品愿景》实现的本地个人研究工作空间。

React + TypeScript 前端，Node.js + Express API，SQLite 持久化。数据和 PDF 保存在本机，默认地址为 **http://127.0.0.1:4317**。

## 启动

需要 Node.js 24 或更新版本。

```powershell
npm.cmd install
npm.cmd run dev
```

生产运行：

```powershell
npm.cmd run build
npm.cmd run test:firefox
npm.cmd run test:desktop
npm.cmd start
```

服务仅监听本机。可通过环境变量 `PORT` 更换端口、`DATA_DIR` 更换数据目录。首次启动默认创建明确标注的计算机视觉示例空间；设置 `SEED_DEMO=false` 可关闭示例数据。

## 使用流程

1. 创建独立研究空间，输入研究方向。
2. 导入 arXiv 链接/ID，或者上传 PDF（最大 30 MB）。arXiv 导入会核验标题、作者、年份与编号，只获取摘要，不自动下载全文。
3. PDF 导入会读取文档元信息和 arXiv 编号，并按编号、规范化标题、文件内容自动去重；同一篇论文的本地 PDF 和网络元信息合并保留。也可手动附加到已有论文。
4. 在「模型设置」配置 Chat Completions 兼容接口、模型 ID 和 API Key。接口地址应包含服务商要求的 `/v1` 等前缀，不包含 `/chat/completions`。
5. 打开论文，点击「整理论文 · 提取技术」。AI 筛选核心技术与必要前置，自动加入技术节点、技术关系及论文关系，同名或同义别名合并，不再要求逐项确认。被判定为无关细节的节点不入图，动态保留筛选结果。
6. 设置中的「保留英文专有名词」默认开启，技术标题使用英文，讲解保留中文。开关可独立保存，不要求先配置模型。旧资料可点击「修复已有资料」补齐元信息、英文别名和研究方向。
7. 输入研究目标生成路线。模型可推荐新的 arXiv 论文；系统逐篇核验编号与标题，验证失败时阻止整条路线保存。论文集合高度重叠的路线自动合并，保留不同能力目标和必要旁支。成功生成的路线由用户选择加入计划。
8. 随时切换学习状态、编辑长期记忆，在 Paper Mode 或 Research Context 中继续对话。

未配置模型时，论文管理、PDF 阅读、图谱浏览、候选确认、学习状态、记忆与日程仍可使用。不会返回模拟 AI 答案。配置后，执行 AI 操作会把相关论文内容和当前空间上下文发送至所选模型服务。

## 图谱与数据规则

- 论文加入库后默认后台获取 PDF 与 HTML，AI 自动整理默认关闭。齿轮中的「论文原文与自动整理」独立控制两项，支持配置导出/导入；关闭自动下载仍可手动获取，开启自动整理而关闭下载时会使用已有资料并保留摘要范围说明。获取或整理失败不撤销论文入库，状态与重试入口在论文详情中显示；相同任务和已缓存文件复用，不重建论文 ID，也不覆盖手动标题、学习状态、笔记与关联。中断任务在下次启动恢复。请求串行节流，PDF 最大 30 MB，HTML 最大 10 MB。
- 论文详情提供「阅读 PDF」「阅读 HTML」和原文获取入口，路线提供「获取路线全文」批量后台获取，批量获取不改变候选论文的入库状态。HTML 优先使用 arXiv 提供的正文，缺失时提供带明确说明的 PDF 文字转换视图。原文按段落/章节保存位置，PDF 使用文件页序号；只有同一明确版本且文本可靠匹配时才在 HTML 段落显示 PDF 页码，不推测页码。HTML 文本本地保存，官方图像按需联网读取，完整离线阅读可使用已缓存的 PDF。
- HTML 阅读支持大纲、逐词查找（当前第几处/总数，绿色框精确围住匹配文字，跨行按实际行框绘制）、字号及常驻四色工具栏。顶部仅保留标题/来源/格式切换一行和工具栏一行；来源的详细转换说明放在悬停提示，窄屏工具栏横向滚动，不另占信息行，后续扩展也应优先复用栏位。鼠标停在高亮原文上可编辑纯文本备注并自动保存；有备注的高亮显示下划线。再次选中高亮的一部分并点击高亮图标可移除整个范围，跨段高亮一起移除；有备注时二次确认，删除也校验版本防止覆盖其他窗口的修改。保存不显示挤压正文的状态行。支持本地草稿恢复及跨窗口冲突保护；更新正文保留旧视图和旧标注，可切换正文版本查看。侧栏收放按钮位于栏上，窄屏一次展开一侧，右栏宽度可拖动或用方向键调节并本地记住。
- 阅读侧栏提供技术、笔记和论文对话。笔记默认打开最近更新的关联笔记；没有关联笔记时只显示「创建笔记」，多个关联笔记时可切换。支持创建、编辑、导出、调整多对多关联或删除，复用笔记库数据与 Markdown 编辑器；聚焦编辑限于右栏，保留原文阅读区域。技术侧栏展示整理给出的有效段落关联、术语匹配及已有手动关联，可定位原文、打开技术详情或移除；暂不提供选文手动关联技术的按钮/下拉框。技术详情的「原文关联段落」反向打开对应视图。
- 论文卡片提供「阅读原文」。阅读窗口占桌面宽度约 90%，原页面呈毛玻璃效果，点击窗口外侧在保存标注后关闭。PDF 模式只保留刷新工具，阅读器的搜索、字号、标注、侧栏与翻译功能仅在 HTML 模式提供。
- HTML 工具栏最右侧的「翻译全文」调用当前模型生成中文译文；要求保留人名及没有公认中文对应的术语，不总结或补充原文。公式/代码、图像和表格结构保持原样，LLM 只翻译可读文字。每批至多约 6,500 字符、60 个片段，带有限相邻原文帮助消歧。每批完成后缓存，失败可继续，已完成译文再次打开不调用模型；保存接口提供的实际 token 用量。扫描件没有可提取文字时无法翻译。
- 完成后可切换仅原文、仅译文、可拖动分隔线的双栏，以及「穿插」模式（原文段落后紧跟对应译文段落）。原文与译文的高亮/备注独立保存；穿插模式也按所属版本保存，不能一次跨两种版本创建标注。搜索与技术联动只使用原文，译文不能作为选段送入论文对话。译文独立存储，不进入正文索引、论文问答、技术整理或路线规划的源材料；仅辅助理解，不保证准确性，出处与事实以原文为准。此阶段没有选段翻译及波浪标记功能。
- 两种图谱支持左键拖动水平和竖直视野，滚轮仍可使用；拖动超过小幅阈值时取消节点点击，普通点击与键盘操作保持可用，拖动不会滚动页面。
- 原有问答与阅读侧栏发送后立即把用户文字显示到对话中并清空已发送输入；回复返回时合并实际历史，不重复显示用户消息，不覆盖后续输入的新草稿。失败时保留用户消息并允许重新编辑。阅读对话支持 Enter 发送、Shift+Enter 换行，中文输入法确认不会误发送；调用阶段沿用服务端实际进度，通过浮窗显示，不挤压正文。待发送/失败消息仅保留在当前页面会话，未完成的失败轮次不写入持久化历史。
- 后续整理要求每项技术返回实际提供的 `sourceParagraphIds`，服务器只关联已保存且属于该论文的有效原文位置，标题不必逐字出现在原文。选文对话按钮把「请解释：‘……’」填入论文对话，不自动请求模型，确认发送后使用选段位置与邻近正文，复用同一论文的完整对话历史和模式上下文。候选论文在发送时明确入库；回答出处绑定本次实际提供的片段，点击跳转原文。模型没有使用出处时，检索片段在折叠区域展示；未经提供的编号不会变成可点击引用。标注备注不发给模型。
- 可选真实检查：`node scripts/check-paper-acquisition.mjs [arXiv ID]` 在独立数据库验证实际 PDF/HTML 下载与索引；`node scripts/check-reader-view.mjs` 检查前一次下载的官方 HTML 阅读画面；`node scripts/check-source-grounding.mjs` 用合成正文验证当前模型的出处与技术关联，仅只读真实配置，密钥不复制到测试数据库。结果均保存在 `test-results/`。
- `node scripts/check-full-translation.mjs` 仅用合成技术段落验证当前模型的中文全文翻译、人名/术语保留与实际 token 用量；只读真实配置，在独立数据库保存结果，不发送真实研究资料。

- 笔记编辑框与文本输入使用本地深色、白色描边的 I 形鼠标指针，替代系统默认的反色/浅色文本指针；插入光标也明确使用深色。普通和沉浸编辑共用此规则。
- 技术与论文详情新增「隐藏节点」勾选框，即时反馈并自动保存，保存失败恢复原状态。它只影响图谱显示，不删除记录、关系或关联笔记；重新整理及论文去重会保留用户选择。
- 节点间距模块右侧提供「全部节点／主要节点／极简节点」切换：全部包含手动隐藏节点；主要显示所有未隐藏节点；极简只显示未隐藏的重要及里程碑技术。论文极简模式按关联技术的最高级别筛选，没有关联技术或只关联普通/次要技术的论文可在全部或主要模式查看。关系聚类、时间轴和目标中心都遵循当前模式，只显示可见节点之间的连线；显示选择按研究空间及技术/论文图谱分别保存在浏览器，默认全部节点。
- 快速笔记的「置顶」按钮用深色表示开启、浅色表示关闭。笔记工具栏右侧提供「沉浸编辑」：只保留工具栏、编辑/预览和保存状态，铺满当前页面但不改变系统窗口大小；再次点击或按 Esc 返回，保留内容与撤销历史。
- 关联笔记入口位于技术「重要性判断」下方及论文「阅读导览」下方。「相连的技术」右侧铅笔可编辑关系，区分当前相连/未相连技术；后者支持中英文搜索、每页最多 20 个。下拉关系以当前技术为主语，支持使用/被使用、扩展/被扩展等所有现有关系及「无关系」，修改同一条图谱边同步更新双方详情。手动年份和关系（包括移除关系）不会被后续 AI 整理覆盖；从相连技术跳转会重置详情滚动到顶部。
- 技术详情始终显示「关联笔记」和「新增笔记 →」；点击直接创建以当前显示的技术名称命名的笔记，关联该节点并打开笔记编辑页，已有笔记链接仍保留。
- 论文库提供上传时间新→旧、旧→新，以及论文年份新→旧→未识别、未识别→旧→新四种排序。默认按上传时间新→旧，选择保存在当前浏览器；上传时间使用首次加入记录的时间，与发表年份及整理时间分开，搜索和状态筛选继续生效。
- 配置中的「年份浏览自动换列」默认关闭，每个年份保留一列；开启后可设定「单列最大节点数」（1–100，默认 10），同一年份超出的节点在右侧续开一列，标注列序号。技术和论文时间轴共用设置，未识别年份也遵循此上限；关系聚类和目标中心布局不受影响。支持保存偏好选项、单独保存外观及个人配置导出/导入。

- 论文库下方新增「笔记库」。每个研究空间独立保存 Markdown 笔记；一篇笔记可关联多篇论文与多个技术节点，同一对象也可关联多篇笔记。详情页通过「笔记标题 →」跳转。删除节点/论文只移除关联，不删除笔记；论文去重会迁移笔记关联。
- 笔记支持标题/正文搜索、Markdown 工具栏、分栏/编辑/预览、公式和表格、撤销/重做、Ctrl+S 保存、自动保存及 `.md` 导出。草稿保存在当前浏览器本机，失败时可恢复；多窗口版本冲突会阻止覆盖并保留草稿，先导出或复制后可重新载入最新版本。笔记正文上限 500,000 字符，包含在研究空间 JSON 导出中，不包含在个人配置文件中。

- 图谱下方的全部技术条目默认折叠。展开后可按节点资料类型、技术种类、研究方向、重要程度和学习状态复选筛选；组内取并集，组间取交集，不勾选时显示该组全部。滚轮在图谱内滚动至边界后不会传递到外层页面，Shift+滚轮可横向滚动。
- 图谱工具栏提供横向和纵向间距滑杆，拖动实时更新；横向 160–480px，纵向 120–420px，默认 270/220px。长标签换行，纵向会为长标签保留必要空间。新增图谱高度滑杆：默认高度和上限都是浏览器完整视口高度，不扣减页面顶部区域，图谱底部可以位于当前屏幕下方；最低 360px（视口更小时以上限为准）。间距和高度按研究空间、图谱类型分别保存，支持恢复默认；缩放控制位于滑杆右侧。
- 论文年份采用最初公开/预印本年份；arXiv 修订年和会议年可能不同。无法识别的年份显示「年份待识别」，不再使用上传年份代替。
- 技术首创年份也允许未知，综述年份不能替代技术年份；重新整理不会用未知年份覆盖已有年份。整理结果逐项校验保留，完整 JSON 字段可从截断输出中恢复；无有效摘要或节点时最多简化重试一次。模型不可用时保留旧摘要或标明来源的原文摘录，动态展示降级原因，不编造技术或关系。
- 论文上传/整理/核验、路线规划、对话、资料修复及重要性评估在原加载框中显示服务端实际执行阶段，如调用大模型、解析 PDF、校验整理结果、逐篇核验推荐论文、合并保存。论文核验显示当前/总数及论文标题；重试和保底也会上报阶段。当前模型接口为非流式请求，等待回复期间持续显示模型调用状态，不编造模型内部进度或百分比。进度按空间与请求隔离，结束/失败/页面卸载后停止查询；进度仅临时保存，刷新后不恢复未完成的任务。
- 每条对话记录本地时间（精确到秒），用户消息为调用前发送时间，助手消息为回复到达时间。助手记录 API 的实际输出 token；悬停用量可查看接口提供的输入/总计/推理用量。齿轮配置中的「显示对话时间」「显示输出 token 数」默认开启，独立保存，可随个人配置导入/导出；关闭显示不会删除记录。旧对话用量显示「未记录」，接口没有有效 `completion_tokens` 时显示「接口未返回」，不估算，也不通过总量减输入量补算。时间与用量不会附加到发给模型的对话历史。
- 右上与左下分别提供「偏好选项」「模型设置」。偏好保存只修改界面、阅读、笔记和学习偏好；模型设置独立保存接口、模型和任务默认思考参数。路线规划、论文整理（含补全与重试）、全文翻译分别配置深度思考和强度，默认由服务商决定；不影响对话面板自身思考设置。仅对已确认协议的 DeepSeek 模型启用参数，未知接口禁用控件且不发送不兼容参数；任务参数支持个人配置导出/导入，文件不包含 API Key。
- 模型设置提供输入与输出两张每日柱状图，可切换最近 7/30 天；悬停、点击或键盘聚焦显示翻译、对话、整理、路线等分类。按浏览器时区汇总全部空间，独立 SQLite 用量账本记录每次调用的实际输入/输出/总计，包含重试及已返回用量但格式错误的调用；不存提示词、论文正文、模型回复或密钥。未返回用量不估算；推理 token 不重复加入输出。升级仅补入原来已保存的对话用量和翻译累计用量，旧翻译归入保存日，历史整理/路线未记录用量无法补算。
- 全文翻译通过后台任务提交（浏览器使用 `background:true`，接口立即返回 202 和任务 ID），离开阅读器、切换页面/研究空间或刷新网页都不影响服务端执行。右下角持续显示真实批次/模型进度，完成或失败保留通知，可进入「动态」查看。服务进程关闭会中断正在执行的调用；再次运行时标为已中断，可从已缓存片段继续翻译。同步翻译接口仍兼容已有调用方。
- 「动态」按当前空间保存路线规划、论文整理及翻译的任务历史、开始/完成时间、状态和 API 实际总 token 用量，支持按类型筛选。一个任务的多次模型调用累计在同一任务内；续译作为新任务，已缓存部分不重复计费。升级会展示已有路线、整理和译文，缺少旧时间或用量分别标为未记录、未提供，不伪造历史数据。任务日志与用量不进入模型上下文。
- 对话区采用紧凑布局：标题与论文/研究模式按钮在同一行，移除上下文、策略说明和描述性小字。输入框默认一行，进入编辑时展开为原高度，退出后收起，多行草稿保留。可调整深度思考（默认/开/关）及强度，偏好独立持久化，只作用于对话。目前适配官方 DeepSeek 的 flash/pro/chat/reasoner，强度为低/高/最高；其他接口禁用思考控件并使用模型默认行为，不发送未经确认的控制参数。参数依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。
- 两种对话默认采用「资料优先，允许补充」：即使没有收录被引用论文或没有全文，也可解释相关背景、外部文献与学习建议；当前资料不能支撑的内容必须就近标注「无资料支撑」，并区分领域知识与推测。该标签表示未获当前资料支持，不等于内容错误。「对话资料策略」只放在齿轮配置中，随「保存偏好选项」生效，可导出/导入。「严格依据资料」只使用给定资料和明确标注的推断，不用领域知识补填事实或推荐。切换作用于后续回答，保留原对话历史。
- Paper 模式只使用当前论文和该论文的模式历史，已有索引时查找相关正文并带必要前后文，允许按资料策略补充相关背景。Research Context 发送当前空间已收录论文的摘要、候选论文元信息/摘要、节点/关系、全部路线及学习记忆，并从已收录论文中检索相关正文；已选路线与备选路线明确区分。候选资料不等于已收录，只有无法匹配论文记录的路线 ID 才列为未解析；候选论文不参与全文检索。两种策略下，是否在论文库/计划/图谱中以及学习状态始终以当前空间记录为准，补充知识不会自动创建论文或节点。
- 可选真实模型策略检查：配置接口后运行 `node scripts/check-chat-policy.mjs`，使用合成摘要与路线检查两种模式、默认补充和严格策略；只读本机设置，不发送真实论文、写入研究空间或改动已保存的思考偏好，结果保存在 `test-results/chat-policy-live/`。标签与回答约束由提示词引导，仍需用户核对模型给出的外部知识。
- 技术详情「引用并打开对话」默认进入 Paper Mode，选择已在论文库中的最早关联论文，并留下「请解释 xxx 技术在这篇论文中的作用，以及其是怎么实现的。」草稿，不自动发送；没有关联的已收录论文时保持待选择状态。选择采用首次入库时间，旧记录回退到原加入时间，同时间按原记录顺序选择；不会把候选论文创建时间或论文发表年份当作入库先后。
- 后续整理论文为每项关联技术生成本文专属的两句话概括，第一句说明作用，第二句说明实现/使用方式，放在论文详情「关键技术」卡片中。复用已有技术也生成当前论文的概括，按论文与技术的关联保存，不覆盖其他论文的解释。原资料未交代实现时明确说明；输出缺失或不完整时保留已有有效句子、显示待补充说明并报告整理局限，不因此丢弃技术。旧论文可通过重新整理生成概括。
- 可选真实整理检查：`node scripts/check-paper-summaries.mjs` 用合成论文与临时研究空间验证两句概括，只读真实设置，密钥仅用于模型请求且不复制到临时数据库，不修改真实论文；结果保存在 `test-results/paper-summaries-live/`。
- 研究方向与技术类型由 AI 根据当前空间和论文主动发现，不预设计算机视觉类别。模型获得当前空间已有分类、别名和节点，优先复用相同概念，按需创建新类别；服务器按名称与别名归一并随空间保存，只展示实际有节点的分类，空空间没有分类预设。旧分类可通过重新整理论文或「修复已有资料」更新，已有节点和学习进度保留。历史英文 ID 的中文映射仅用于显示旧数据。
- 路线合并阈值：共享论文占较小路线至少 80%、占较大路线至少 65%。只共享少数前置论文的路线保持独立。
- 升级时对旧空间自动进行本地去重、年份修正、方向归类和路线合并。变更前的完整空间快照保存到 `data/backups/`，不修改或删除原始 PDF。

## 当前边界

- 这是可运行的第一阶段基础版本，面向本机单用户；不包含账户、云同步、多用户权限或跨 Workspace 引用。
- 扫描件 OCR 和图像内容理解暂未实现。HTML 保留 MathML 公式、表格与图像，PDF 转换视图可能缺失这些元素。索引覆盖成功提取的正文，使用关键词、问题意图词与中英技术名称扩展检索（尚未使用向量语义模型），每次提供至多 14 个片段及 24,000 字符；检索未命中不代表全文没有相关内容。整篇概括采用章节代表片段，也不代表逐段完整阅读。整理最多提供 85,000 字符的原文，超出范围必须注明局限。
- AI 历史归因与推荐相关性仍需人工核对。arXiv 核验保证编号、标题与元信息匹配，不能代替论文内容审查。核验网络失败时可重试，不会把失败项标记为 Verified。
- AI 不会自动把用户标为「已学会」，也不会自动写入隐形长期记忆。当前长期记忆由用户显式维护。
- 不包含愿景明确暂缓的测验、评分、间隔复习、社交及复杂多 Agent 自治。

## 保存与备份

`data/paper.sqlite` 保存全部结构化数据与模型设置；`data/files/` 保存 PDF。API Key 保存在本机 SQLite 中，未加密，接口不会回传 Key；不要共享数据库或提交到版本库。

设置中的 JSON 导出仅包含当前空间的结构化资料与提取文本，不含 PDF 二进制和全局 API Key。完整备份请先停止服务，再复制整个 `data/` 目录；恢复时替换对应目录。

## 代码导航

- `src/App.tsx`：主工作空间与交互界面。
- `src/Graph.tsx`：技术/论文时间图谱。
- `src/graphLayout.ts`：节点排布、标签换行、双向关系箭头。
- `src/Markdown.tsx`：安全 Markdown、GFM 表格与 KaTeX 数学公式渲染。
- `src/style.css`：界面样式与响应式布局。
- `server/app.mjs`：空间作用域 API、文件处理、图谱审阅与路线门禁。
- `server/services.mjs`：arXiv 验证、模型接口、隔离上下文构造。
- `server/translation.mjs`：按原文片段分批翻译、格式保留、缓存续传与译文隔离。
- `server/store.mjs`：SQLite 持久化。
- `server/research.mjs`：论文身份与去重、方向归类、路线合并、自动入图和旧数据迁移。
- `server/repair.mjs`：模型辅助的旧资料修复，核验身份后保留原有文件和学习状态。
- `server/seed.mjs`：人工示例空间；示例学习状态不代表真实用户进度。

技术依据：[Node.js SQLite](https://nodejs.org/api/sqlite.html)、[Vite](https://vite.dev/guide/)、[pdf-parse](https://www.npmjs.com/package/pdf-parse)。示例元信息来自 [VGG](https://arxiv.org/abs/1409.1556)、[ResNet](https://arxiv.org/abs/1512.03385)、[Transformer](https://arxiv.org/abs/1706.03762)、[ViT](https://arxiv.org/abs/2010.11929)、[Batch Normalization](https://arxiv.org/abs/1502.03167)、[Swin Transformer](https://arxiv.org/abs/2103.14030)。图谱导览关系与论文存在性验证分开处理。
